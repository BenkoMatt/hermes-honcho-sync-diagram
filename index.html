⚡ Hermes + Honcho Multi-Profile Memory Sync

All non-isolated profiles write facts about the same user to a single shared user peer. Each profile keeps its own AI identity.

1. Shared User Peer

your-user-peer in workspace hermes is now the single destination for facts about you. All non-work profiles write and read from it.

2. Distinct AI Peers

Each profile keeps its own AI identity (profile-a, profile-b, profile-c, etc.). Their self-representations are separate.

3. Isolated Work Profile

Isolated profiles use built-in memory only and have no Honcho connection.
